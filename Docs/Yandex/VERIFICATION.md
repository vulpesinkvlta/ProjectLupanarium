## Границы проверки

Реальная реклама Яндекса, аккаунт монетизации и модерация проверяются в черновике платформы по инструкции README. Тестовый SDK не подтверждает наличие рекламного заполнения.

Проверен desktop-интерфейс. Текущие большие панели не адаптированы для узкого портретного окна; мобильную поддержку в заявке пока не включать без отдельной адаптации и проверки на устройствах. Safari и Firefox не проверялись.

В Chromium есть предупреждение URP о недоступном FSR/post-processing shader; меню, арена и UI отрисовались. Есть предупреждение Unity об устаревающем ручном sync persistentDataPath; сохранение и восстановление PlayerPrefs фактически проверены.

Контентные ассеты `Assets/Configs` не изменены. Архив содержит текущих гладиаторов и существующие тексты; для выпуска brainrot-версии сначала замените назначенные каталоги/визуалы и пересоберите.

Для повторения локальной проверки: `python Tools/Yandex/serve-preview.py --mock-sdk`. Без `--mock-sdk` проверяется запуск при отсутствии SDK; сервер привязан только к 127.0.0.1.
